<h1 align="center">TF1 Maps</h1>
<h3 align="center">Titanfall 1 maps not included in Titanfall 2</h3>

This project documents 19 multiplayer maps from the original **Titanfall** that are not included in **Titanfall 2**. Each map has its own README under `maps/`.

## Game modes

The IDs are the names used in the playlist configuration. The names after are ingame mode names.

| Playlist ID | Player-facing name |
|---|---|
| `tdm` | Team Deathmatch |
| `aitdm` | Attrition |
| `cp` | Hardpoint |
| `at` | Bounty Hunt |
| `ctf` | Capture the Flag |
| `lts` | Last Titan Standing |
| `ps` | Pilot Skirmish |
| `speedball` | Speedball |
| `mfd` | Marked for Death |
| `ttdm` | Titan Team Deathmatch |
| `fastball` | Fastball |
