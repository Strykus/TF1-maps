<h3 align="center">Titanfall 1 maps not included in Titanfall 2</h3>

## Game modes

The IDs are the names used in the playlist configuration. The names after the dash are player-facing mode names.

| Playlist ID | Player-facing name |
|---|---|
| `tdm` | Team Deathmatch |
| `aitdm` | Attrition |
| `cp` | Hardpoint |
| `at` | Bounty Hunt |
| `ctf` | Capture the Flag |
| `lts` | Last Titan Standing |
| `ps` | Pilot Skirmish |
| `speedball` | Speedball |
| `mfd` | Marked for Death |
| `ttdm` | Titan Team Deathmatch |
| `fastball` | Fastball |
